# Minigame 1
## Devlog
Imagine the game to be a film. A film usually involves multiple places, thus requiring multiple scenes (Scenes). The GameObjects are like everything used to make up those scenes, such as the environment, characters, and props.
For example, you may want a character that can move in the scene. That would be a GameObject. You may also want a fan that can blow. However, GameObjects in Unity don't have those functions built in. So Components are like logical features that objects can have. For example, adding a Component to the character can give it the feature of movement. You can also add that same feature (Component) onto the fan, and then it can also move, if you want.
